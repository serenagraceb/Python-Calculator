# Python Calculator

A simple command-line calculator developed using Python in Jupyter Notebook.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Invalid operator handling
- Option to continue or exit after each calculation

## Concepts Used
- Python variables
- User input
- Conditional statements
- Loops
- Arithmetic operators

## Tools Used
- Python
- Jupyter Notebook

## How to Run
1. Download the Jupyter Notebook.
2. Open it using Jupyter Notebook.
3. Run the cells.
4. Enter the numbers and operator when prompted.
5. Choose whether to continue or exit.
